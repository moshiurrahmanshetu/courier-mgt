This folder should contain user avatar images.

PLACEHOLDER FILE: default-avatar.png
- Add a default avatar image named "default-avatar.png" to this folder
- Recommended size: 200x200 pixels
- Recommended format: PNG with transparent background
- This image will be used for users who haven't uploaded their own avatar

User avatar naming convention:
- user_[user_id]_[timestamp].ext
- Example: user_1_1691234567.jpg
- Allowed formats: JPG, JPEG, PNG
- Maximum file size: 2MB
