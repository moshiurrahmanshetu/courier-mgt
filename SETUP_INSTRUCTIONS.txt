COURIER MANAGEMENT SYSTEM - PHASE 1 SETUP INSTRUCTIONS
=======================================================

PHASE 1 SCOPE: Project Skeleton + Authentication + Role Foundation + Dashboard Shell

SETUP STEPS:
============

1. DATABASE SETUP:
   - Create a new MySQL database named: courier_management_system
   - Import the SQL file: database/auth_users.sql
   - This will create the roles and users tables with seed data

2. DEFAULT AVATAR:
   - A default avatar SVG has been provided: assets/images/avatars/default-avatar.svg
   - You can replace this with a PNG image if desired (rename to default-avatar.png)
   - Recommended: 200x200 pixel PNG with transparent background
   - The system will work with the provided SVG placeholder

3. CONFIGURATION:
   - Check config/config.php and adjust database credentials if needed:
     * DB_HOST (default: localhost)
     * DB_NAME (default: courier_management_system)
     * DB_USER (default: root)
     * DB_PASS (default: empty)

4. ACCESS THE APPLICATION:
   - Open in browser: http://localhost/courier-mgt/
   - Default admin credentials:
     * Username: admin
     * Password: Admin@123

DELIVERABLE CHECKLIST:
=====================
After setup, the following should work:

1. Visiting the project shows login.php if not logged in
2. Login with seeded admin credentials (username: admin / password: Admin@123) logs in successfully
3. After login, dashboard.php loads with header, collapsible sidebar, and welcome message
4. Sidebar collapse/expand works and persists on page reload
5. Profile edit works (name/email/phone update + avatar upload/change)
6. Change password works and you can log out, then log back in with the new password
7. Logout properly destroys session and redirects to login
8. Trying to access dashboard.php or profile.php directly without login redirects to login.php

FEATURES INCLUDED:
=================
- Authentication system (login, logout, session management)
- Role-based access control (Admin, Staff, Delivery Staff)
- User management (CRUD operations with soft delete)
- Profile management (edit personal info, avatar upload)
- Password change functionality
- Collapsible sidebar with localStorage persistence
- Professional flat design (no gradients, muted teal accent color)
- Responsive design for mobile devices
- Form validation (client-side and server-side)
- PDO with prepared statements for all database queries
- Error handling with logging (no raw SQL errors exposed)

IMPORTANT NOTES:
===============
- All database queries use PDO with prepared statements
- No gradients, pink, purple, magenta, or blue-toned gradients in UI
- Professional color scheme: muted teal (#0d6e6e) + neutral tones
- Session validation on all protected pages
- Avatar upload: JPG/JPEG/PNG only, max 2MB
- User deletion is soft delete (is_active flag toggle)
